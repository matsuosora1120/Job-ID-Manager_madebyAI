# 就活エントリー管理 Webアプリ

就職活動における企業情報やログイン情報、選考状況などを一元管理するために作成したWebアプリです。

## 概要

就職活動中に増えていく企業ごとのログインIDやパスワード、マイページURL、選考状況などをまとめて管理できるように開発しました。

企業情報の登録・編集・削除に加えて、業界による絞り込みや選考ステータスの管理、登録したマイページへの直接アクセスなどができます。

## 主な機能

* ユーザーログイン機能
* 企業情報の新規登録・編集・削除
* ログインID・パスワードの管理
* マイページURLの登録・リンクアクセス
* 業界による企業情報の分類
* 選考ステータスの管理
* 業界による企業一覧の絞り込み
* Googleスプレッドシートとのデータ連携
* PC・スマートフォンからの利用を想定したUI

## 使用技術

* Python
* Streamlit
* pandas
* gspread
* Google Sheets API
* Google Cloud

## データ管理

企業情報の保存先にはGoogleスプレッドシートを使用しています。

`gspread`を利用して、Webアプリからデータの取得・追加・更新・削除を行えるようにしています。

また、ローカル環境では認証情報ファイル、クラウド環境ではStreamlit Secretsを利用することで、環境に応じてGoogleスプレッドシートへ接続できるようにしています。

## 開発について

本アプリは、生成AIを活用して開発しました。

自分自身の就職活動で感じた「企業ごとのログイン情報やマイページURLを管理する手間」を解決することを目的として、必要な機能や画面構成を考え、生成AIを利用しながら実装・改善を行いました。

生成AIによるコード生成だけでなく、実際にアプリを動かしながらUIや操作性を確認し、必要な修正を行うことで、自分の用途に合わせたアプリへ調整しています。

## 開発目的

就職活動では企業ごとに異なるマイページやログイン情報を管理する必要があり、情報が増えるほど管理が煩雑になります。

そこで、普段利用しているGoogleスプレッドシートをデータ保存先として活用し、必要な情報をWeb上から簡単に登録・確認できる仕組みを作りました。

今後は、選考日程の管理や検索機能などを追加し、より使いやすい就活管理ツールへの発展を検討しています。

## 注意事項

本リポジトリでは、実際のログイン情報やGoogle Cloudの認証情報などの機密情報を公開しないようにしています。

実際に利用する際は、認証情報をソースコードに直接記載せず、環境変数やStreamlit Secretsなどを利用して安全に管理することを推奨します。
